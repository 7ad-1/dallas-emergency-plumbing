# Launch Checklist (do these in order)

## 0. Prep (5 min)
- [ ] Replace `(214) 555-0142` with your real phone in all 4 HTML files
- [ ] Replace `example.com` with your real domain in all HTML files + sitemap.xml
- [ ] Push repo to GitHub

## 1. Free hosting (GitHub Pages) — 10 min
- [ ] Create GitHub repo (e.g. `dallas-plumber-site`) and push these files
- [ ] Repo Settings → Pages → Source: GitHub Actions
- [ ] Workflow `deploy.yml` runs automatically; site live at `https://<user>.github.io/<repo>/`

## 2. Free domain options
- GitHub Pages gives a free `*.github.io` subdomain (no purchase needed)
- For a custom free-ish domain: Freenom (limited), or use your own cheap domain (~$10/yr)
- Update `sitemap.xml` + canonical URLs to match live URL

## 3. Google Business Profile (human verification required)
- [ ] Claim at business.google.com
- [ ] Verify via phone/postcard (Google requires this — cannot be automated)
- [ ] Add NAP, hours, photos, services, website link

## 4. Call tracking + monetization (human signup required)
- [ ] Sign up CallRail (or similar) — ~$45/mo; get tracking number
- [ ] Forward tracking number to your phone
- [ ] Email 3-5 contractors using OUTREACH_TEMPLATES.md; agree on per-call price

## 5. Citations & reviews (manual but templated)
- [ ] Submit to Yelp, Angi, BBB, chamber, Nextdoor, Apple Maps, Bing Places (use template)
- [ ] Ask 10 customers for reviews (use SMS template)

## 6. Content cadence
- [ ] Publish 1 new page/week (neighborhoods, cost guides) via marketing-content-creator agent
- [ ] Track rankings + calls + revenue weekly
